# Korean Bridge

Responsive interactive concept for a Kazakhstan ↔ South Korea student community and admissions planner.

## Run

Open `index.html` in a modern browser. No build step, backend, package install, or external JavaScript library is required. Google Fonts and campus photos load from the internet; the interface remains usable if they are unavailable.

## What is included

- Social feed with topic filters, likes, saved posts, comments, demo translations, and post creation.
- Admissions tracker with editable local tasks and progress calculation.
- University catalog with search, city filter, favorites, and detail panels.
- Communities, demo join/create actions, and local message conversations.
- Anonymous question flow, profile view, theme switch, and notification panel.
- Local state stored in browser `localStorage`.

All admissions criteria, dates, events, and translations are illustrative demo content. No backend, identity service, or external translation API is connected. Anonymous question author names are not exposed in the rendered question list; this prototype does not provide server-side privacy guarantees.
